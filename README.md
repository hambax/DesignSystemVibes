# Design Semantics Explorer (DesignSystemVibes)

**Learn how your design system feels to users** — play with corner radius, colour, shadows, and effects, and read plain-language notes on the vibes those choices tend to suggest.

Use this free tool to explore design systems and how changing subtle parameters can lead to different aesthetics and user feelings about your product.

**Live:** open `index.html` in a browser, or use GitHub Pages if you enable it for this repository.
